# 生产线实时可视化 · 智能工厂 MES

生产管理系统产线可视化的单文件 Three.js 场景：PCBM、BMS、电池与维修返测线体的工位状态、良品 / 不良品出口与故障告警。

- 在线访问：<https://daiyu3659.github.io/mes-production-line/>
- 本地使用：双击 `index.html`，或用任意静态服务器打开

## 操作

- 左键拖动：旋转视角
- 滚轮：缩放
- 右键拖动：平移
- 点击工位：查看工位数据
- `ESC`：关闭弹窗
- 右上角「复位视角」「数据口径」：恢复视角、查看字段说明

## 数据说明

页面内的产量、节拍、良率与告警均为**演示数据，非真实生产**。

## 技术要点

Three.js 与全部样式、脚本内联在单个 `index.html` 中，无构建步骤、无外部依赖、无后端，静态托管即可运行。
